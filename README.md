# Guess the Number Game 🎮

A simple, interactive console-based game built in C. This project was created during my 1st year (2nd semester) to practice basic programming concepts.

## 🚀 Features
- Generates a random number between 1 and 100.
- Tracks your total number of attempts.
- Gives instant feedback ("Too high!" or "Too low!").

## 🛠️ Concepts Learned
- Loops (`do-while`)
- Conditional logic (`if-else`)
- Random number generation (`srand` and `rand`)

## 💻 How to Run
1. Open this code in any C compiler or IDE (like Code::Blocks, Dev-C++, or VS Code).
2. Compile and run `main.c`.
3. Enter numbers in the console until you guess correctly!
